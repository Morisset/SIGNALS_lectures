## What to do to prepare yourself for the lectures:
 
- **Install CLOUDY**. We will use the last version c23.01, available from here: https://www.nublado.org/ . You need to download it and install it (compile and test).
- **Python libraries**: You need to create a dedicated environment using conda. First update conda to have the latest avaiable version by `conda update -n base conda`. Then create an environment using the env_PhWorkshop.yml file found in this github repository. Run: `conda env create -f=env_PhWorkshop.yml`
- **The notebooks of the lectures**. They will be available from the following repository: https://github.com/Morisset/SIGNALS_lectures/tree/2025_Toronto.
